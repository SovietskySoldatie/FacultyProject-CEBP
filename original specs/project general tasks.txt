Tasks:
Implement a solution for the chosen topic. The program must be complete and working. You may use any tools during development, including AI code generation. However, you must thoroughly understand the concepts and techniques the solution employs, and be able to reason about optimization, changes, and alternatives. Students will be asked questions about the concurrency issues avoided, functionality, primitives and concepts used..
Implement at least two faulty solutions for the chosen topic. You may still use AI for code generation if needed. The programs must have intentional errors that relate to concurrency. One solution should mainly focus on data races and data consistency, while the other should focus on issues like deadlock, livelock, and performance. Students will be asked questions about concurrency issues, the approaches for solving them, and about synchronisation primitives.
